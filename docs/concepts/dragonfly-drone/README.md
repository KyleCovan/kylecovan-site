# Dragonfly drone — concept pack

**Status:** concept only. Not a site build. Not started as hardware.
**Opened:** 2026-08-10
**Ask:** a remote-controlled dragonfly-sized drone with a camera, flown from an iPhone.

This folder is the engineering workup so the idea can be accepted, deferred, or killed with eyes open. It is **not** published on kylecovan.com. If it becomes a real build later, copy moves into `src/content/builds/` in Kyle's voice — not from this brief.

| File | What it is |
|---|---|
| [`design-brief.md`](design-brief.md) | Feasibility, architecture options, recommended path |
| [`weight-budget.md`](weight-budget.md) | Mass budgets by target class |
| [`iphone-stack.md`](iphone-stack.md) | Control + video from iOS |
| [`bom-phase-1.md`](bom-phase-1.md) | First-hardware shopping list |
| [`decision-gates.md`](decision-gates.md) | Go / no-go checkpoints |

**One-line verdict:** a *true* dragonfly (few grams, insect silhouette, flapping wings) with a useful camera and an iPhone link is research-lab hard. A *dragonfly-looking* micro quadrotor you can fly from an iPhone is doable as a staged DIY project, starting from an existing ~25 g phone-controlled kit and then cladding / shrinking the airframe.

Found a real gap in my AI operating system setup and started wiring the fix today.

The morning briefing and nightcap work great. But they only see inside their own folder. All the work I do in other projects is invisible to the brain.

Wiring what I'm calling a synapse: a registry of all my project folders + a pulse script that registers the folder on session start and logs which ones I was in at session end and each agent stop + `synapse-status.sh` so morning/nightcap can see the whole day.

Three pieces. All three are wired.

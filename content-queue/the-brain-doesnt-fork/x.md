canceled my Claude app subscription today. Cursor is my only AI surface now.

that created a temptation: copy my AI OS into every Cursor project so it follows me.

that would've been wrong. two copies drift. one update misses the other. within weeks you have two brains neither of which fully is.

better move: a thin pointer instead of a copy. the files are plain markdown. readable from anywhere with a path. i wrote a User Rule that points at them on demand.

one brain. one pointer. no fork.

the files don't care which tool reads them. only the delivery layer changed.

if you're building a second brain or AI OS, hold this: when you switch surfaces, don't replicate. build surface-agnostic files and teach each surface to find them.

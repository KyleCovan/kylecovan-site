## Option C (short thread) — STALE from item 6 onward

1/ Turning a 2019 iMac into an always on home server. Notes from day one, including the parts I got wrong.

2/ The iPad was out immediately. Not because it is slow. iPadOS suspends background processes, so it cannot run a server at all. Good client, never a server.

3/ Found a decision log entry where I had already picked the iMac two weeks ago and forgotten. Arrived at the same answer twice. Sound reasoning, wasted time.

4/ My own note said the iMac was "still getting security updates." True when I wrote it. Not true now. Ventura fell off Apple's support window.

5/ A decision log is not a set of facts. It is facts as of a date. Software support facts have a short shelf life.

6/ Was tempted to use my M1 Pro instead. Better in every measurable way. Did not, because it is my working machine and the fallback was a 2015 laptop that cannot run a supported macOS.

7/ Then it clicked: local models do not belong on an always on box anyway. Running a model is interactive. It belongs on the machine you are sitting at.

8/ Biggest surprise: the power bill. 47W idle is about $13 a month here. The electricity costs three times more than the software.

9/ Full build log is up.

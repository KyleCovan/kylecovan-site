**Thread**

1/
Two AI coding sessions on the same project last night.

One building report pages. One doing homepage copy with me.

Both running in the same folder. Neither knew the other existed.

2/
Found out when one listed the changed files and there were more than it had touched.

3/
Nothing was broken. They'd worked on different files.

The one file they both edited, they'd edited in different spots.

Luck, not design.

4/
Then I said I was about to save and upload.

The session stopped me. It was right to.

5/
Saving "everything that changed" would have bundled the other session's finished work in with an evening of unreviewed edits.

On this project, uploading isn't a save. It rebuilds the live site.

Whole evening goes public in one move.

6/
And switching to the main version, the normal step before merging, would have made a pile of files vanish from the folder.

They only lived on the other session's branch.

They'd come back. But I'd have spent 20 minutes at midnight thinking I deleted a day of work.

7/
Fix was small.

Session one wrote down where it got to before closing, including which files weren't its own.

Session two read that and saved only its four.

8/
What I'd change: decide up front which session owns which files. Have each one say so when it starts.

Two agents in one folder is fine.

Two agents that both think they're alone is how you lose an evening.

9/
The habit that saved it: asking before saving, not after.

It had everything it needed to just go ahead.

It stopped and told me what I was about to do instead.

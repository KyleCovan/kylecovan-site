spent an afternoon confused by one word. "cloud" was doing two jobs.

one cloud is a brain. the thinking happens on their servers. no folder, no terminal, no copy of your repo. it just reasons.

the other cloud is a machine. a temporary linux box that clones the repo, runs commands, opens a browser. those are hands.

brain and hands. two different things wearing one word.

running an agent on your laptop vs in the cloud uses the same brain. only difference is whose hands. your laptop has to be awake. the cloud VM doesn't care if your laptop exists.

that answered the saving question too. github is the shelf they both reach for. neither reads the other's hard drive. want yesterday's work visible to a cloud agent? push it. nothing gets there by being nearby.

and my phone, which i had backwards: no machine attached to it. it can't work a repo alone. it talks to the brain and picks which hands to use. remote control, not workstation.

none of this was hard once i had words for it. it was hard while one word meant two things.
